# dataformats — notes on the original game's data files

This directory collects **our own written analysis** of the file formats found
on the game disc. Everything here is our description and reasoning.

## House rules

- Only our own writing goes here. No hex dumps, no byte-level extracts, no
  string dumps copied out of the game — those belong in `build/` (gitignored)
  and must never be committed.
- A good note describes: which file(s) it covers, the suspected structure,
  how the structure was established (which probe/trace/disassembly led to the
  conclusion), and open questions.
- Reports generated by the pipeline live in `build/reports/`; a note here
  should *refer* to them, not copy them.

## Conventions

Name files after the format family they describe, e.g.:

- `overview.md` — the disc layout: what files exist and which engine
  subsystem (graphics / audio / text / savegame / level data) they feed.
- `graphics-*.md`, `audio-*.md`, `savegames.md`, `text.md` …

Each note should start with a status line:

```
Status: hypothesis | probing | confirmed
```

Update the status as the evidence accumulates.
